# WiliPirate

WiliPirate is a planned FREE-WILi 2 Wili/OneWili script/application inspired by
Bus Pirate and ESP32 Bit Pirate, with selected functionality to be reimplemented
against supported FREE-WILi APIs after source and license research.

It is not replacement MAIN or DISPLAY firmware. Stock firmware is preserved.
The initial milestones cover research and a minimal application with help, info,
and mode commands. Hardware operations and electrical pin mappings are deferred.
Launching the application must not drive external pins or enable target power.

Upstream projects are references; no upstream source is included in this setup.
